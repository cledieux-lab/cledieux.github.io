Snake 2000 – console game in C

In progressCAlgorithmsModular programming

Context
University programming project: develop a classic Snake game running in the console, using a provided helper library (myLib) and a modular structure split into sub-programs (SP_*).
My role
Developing the game logic, in particular the snake head movement (SP_MOVE_TETE) and the keyboard handling (SP_Gestion_Clavier, non-blocking input with kbhit / getkey).
What it includes
Main menu (play / options / quit); configurable options: colours of the field, walls and snake, field height and width, game speed.
Methods & tools
C, header files (myLib.h, mesTypes.h, SP_options.h, SP_jeu.h), game loop, structured sub-programs.
